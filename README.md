# Micro FPV RC car 1:64 на XIAO ESP32S3 Sense

Радиоуправляемая FPV-машинка размера Hot Wheels (1:64): видео с камеры и управление прямо из браузера телефона по Wi-Fi.
Никаких приложений и пультов: подключаешься к машинке, открываешь трансляцию, а на экране сразу появляются два джойстика и кнопка фар.

Прошивка основана на [ESP32-CAM_MJPEG2SD](https://github.com/s60sc/ESP32-CAM_MJPEG2SD) v10.9.6 от **s60sc** и доработана под машинку (список изменений ниже).

## Возможности

- 🎮 **Два экранных джойстика** поверх видео (мультитач, можно рулить и газовать одновременно):
  - левый — руль (только влево/вправо);
  - правый — газ вперёд / задний ход (только вверх/вниз), скорость пропорциональна отклонению;
  - при отпускании джойстики возвращаются в центр: руль выравнивается, мотор останавливается.
- ⇄ **Кнопка смены джойстиков местами** (газ слева, руль справа); выбор запоминается в браузере телефона.
- 💡 **Кнопка фар**.
- Джойстики появляются **автоматически** при открытии трансляции.
- ⚙️ **Настройка руля**: крайние точки влево/вправо и центр задаются в градусах, сервопривод сразу встаёт в положение, пока вводишь число; инверсия руля — обменом значений «лево/право».
- 🔁 **Инверсия мотора** галочкой: перепутанные провода мотора не нужно перепаивать.
- 🚀 **Плавный разгон мотора** (soft start): снижает пусковой ток, машинка не выключается от просадки питания.
- 📶 **Регулировка мощности Wi-Fi** для снижения пиковых токов.
- 🛑 **Защита при потере связи**: мотор останавливается, руль выравнивается, если браузер перестал отвечать (heartbeat 2 с), свёрнут или трансляция закрыта.
- Прошивка обновляется **по Wi-Fi (OTA)** — без разборки машинки.

## Компоненты

| Компонент | Примечание |
|---|---|
| Seeed Studio **XIAO ESP32S3 Sense** | с платой камеры и слотом microSD |
| Камера **OV2640** (24 pin) | подходят OV3660 / OV5640; для FPV удобнее широкоугольный объектив 100–160° |
| microSD-карта | для веб-страниц и настроек |
| Драйвер мотора **MX612E** (SOP-8) | H-мост |
| Линейный микросервопривод **1.5 г** | руль |
| Мотор с двойным валом | колёса прямо на валу |
| LiPo 1S, 3.7 В | несколько маленьких банок параллельно (2 × 50 мА·ч мало — см. «Питание») |
| Белые светодиоды + резисторы | фары |
| Конденсаторы | см. «Питание» |

## Подключение

| Пин XIAO | GPIO | Куда |
|---|---|---|
| **D0** | 1 | сигнал сервопривода руля |
| **D1** | 2 | MX612E INA (ножка 2) — «вперёд» |
| **D2** | 3 | MX612E INB (ножка 3) — «назад» |
| **D3** | 4 | фары |
| BAT+ / BAT− | — | аккумулятор (площадки снизу XIAO) |

⚠️ **D8, D9, D10 (GPIO 7, 8, 9) не использовать** — они заняты SD-картой.
Все пины можно поменять в веб-интерфейсе: *Edit Config → RC Config*.

### MX612E (SOP-8)

```
        ┌───●───────┐
 VCC  1 ┤           ├ 8  OUTA ── мотор
 INA  2 ┤  MX612E   ├ 7  GND
 INB  3 ┤           ├ 6  GND
 VDD  4 ┤           ├ 5  OUTB ── мотор
        └───────────┘
```

| Ножка | Куда |
|---|---|
| 1 VCC (питание логики) | 3V3 XIAO |
| 2 INA | D1 |
| 3 INB | D2 |
| 4 VDD (питание мотора) | BAT+ |
| 5 OUTB, 8 OUTA | мотор |
| 6, 7 GND | GND |

### Сервопривод

| Провод | Куда |
|---|---|
| питание (+) | **BAT+** (не 3V3 — стабилизатор XIAO не выдержит пики тока сервопривода) |
| земля (−) | GND |
| сигнал | D0 |

### Фары

- Просто: `D3 → резистор 33–47 Ом → светодиод → GND`, у каждого светодиода свой резистор, всего ≤ 20 мА.
- Ярче: светодиоды от BAT+ (резистор 68–100 Ом на каждый) через N-MOSFET AO3400 / SI2302, затвор на D3, 10 кОм затвор–GND.
- Пин 5V на XIAO **не подходит** — на нём есть напряжение только при подключённом USB.

GND общий у всех: XIAO, драйвер, сервопривод, светодиоды, аккумулятор.

## Питание

Маленькие LiPo проседают при старте мотора, и XIAO перезагружается. Что помогает (по убыванию эффекта):

1. **Больше банок параллельно.** С 2 × 50 мА·ч машинка выключалась, с 3 × 50 мА·ч — уже нет.
   Банки должны быть одного типа (LiPo 3.7 В, заряд до 4.2 В), перед соединением выровняй напряжение до ±0.05 В.
   Ёмкость может отличаться.
2. **Плавный разгон** (`motorRamp`) и ограничение газа (`maxDutyCycle` 70–80 %).
3. **Конденсаторы:**
   - 10 мкФ (106) керамика 0805 X5R 16 В — у MX612E между VDD и GND;
   - 100 нФ (104) — прямо на выводах мотора;
   - 47–190 мкФ тантал (например, 476J — 47 мкФ 6.3 В) — на 3V3/GND XIAO, полоска = плюс.
     ⚠️ Танталы на 6.3 В **не ставить на линию аккумулятора** — нужен запас по напряжению ×2; туда керамику 107 (100 мкФ) 1206 или полимерный.
4. **Мощность Wi-Fi** 11 dBm (`wifiTxPower`).

⚠️ Если у банок **нет платы защиты**, поставь одну общую плату защиты 1S (DW01 + 8205) на всю сборку. Никогда не паяй ничего на разъёме, подключённом к незащищённому аккумулятору: капля припоя между контактами — короткое замыкание.

## Сборка и прошивка

1. Arduino IDE, ядро **esp32 by Espressif v3.1.1** или новее.
2. Открыть `ESP32-CAM_MJPEG2SD/ESP32-CAM_MJPEG2SD.ino` (папка должна называться так же, как `.ino`).
3. Настройки платы:
   - Board: **XIAO_ESP32S3**
   - PSRAM: **OPI PSRAM**
   - Partition Scheme: **8M with spiffs (3MB APP/1.5MB SPIFFS)**
4. Прошить по USB. Если не подключается — зажать кнопку **B (BOOT)**, вставить USB, отпустить.
5. При первом запуске подключиться к точке доступа камеры, ввести данные своего Wi-Fi.
   Веб-страницы прошивка **сама скачает из этого репозитория** на SD-карту (нужен интернет).
   Без интернета — скопировать папку `ESP32-CAM_MJPEG2SD/data` в корень SD-карты.

### Обновление по Wi-Fi (OTA)

1. В Arduino IDE: *Sketch → Export Compiled Binary* — в папке `build` появится `ESP32-CAM_MJPEG2SD.ino.bin`.
2. Открыть `http://<IP машинки>/web?OTA.htm`, загрузить `.bin`.
3. Через эту же страницу можно загрузить `MJPEG2SD.htm` (ляжет в `/data` на SD-карте).

## Настройки (Edit Config → RC Config)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `steerLeft` | 45 | угол сервопривода при джойстике до упора **влево**, 0–180 |
| `steerCenter` | 90 | угол в центре (подстройка «прямо») |
| `steerRight` | 135 | угол при джойстике до упора **вправо**, 0–180 |
| `motorInvert` | выкл | поменять «вперёд» и «назад» |
| `motorRamp` | 300 | плавный разгон: мс от 0 до 100 % газа (0 — выкл) |
| `minDutyCycle` | 15 | минимальный газ, при котором мотор трогается, % |
| `maxDutyCycle` | 100 | максимальный газ, % |
| `pwmFreq` | 5000 | частота ШИМ мотора, Гц |
| `heartbeatRC` | 2 | через сколько секунд без связи останавливать мотор |
| `wifiTxPower` | Max | мощность Wi-Fi: Max / 15 / 11 / 8.5 dBm |

- Пока вводишь `steerLeft` / `steerCenter` / `steerRight`, сервопривод сразу встаёт в это положение.
- Руль поворачивает не туда — поменяй местами значения `steerLeft` и `steerRight`.
- Крайние точки могут быть несимметричными (например 70 / 95 / 110).
- Новые параметры прошивка сама добавляет в старый `configs.txt` — удалять его не нужно.
- Для меньшей задержки видео ставь разрешение VGA (640×480) или ниже.

## Изменения относительно ESP32-CAM_MJPEG2SD 10.9.6

**Прошивка**
- `ESP32-CAM_MJPEG2SD.h` — выбрана плата `CAMERA_MODEL_XIAO_ESP32S3`, включены `INCLUDE_PERIPH` и `INCLUDE_MCPWM`.
- `src/appSpecific.cpp` — настройки RC по умолчанию (пины, ШИМ 5 кГц, heartbeat 2 с, детектор движения выключен), новые параметры `steerLeft/Center/Right`, `motorInvert`, `motorRamp`, `wifiTxPower`; при потере связи руль выравнивается.
- `src/peripherals.cpp` — пересчёт положения руля через крайние точки и центр, предпросмотр положения сервопривода при настройке.
- `src/mcpwm.cpp` — разрешение таймера MCPWM 1 МГц, инверсия мотора, задача плавного разгона.
- `src/prefs.cpp` — недостающие параметры автоматически добавляются в существующий `configs.txt`.
- `src/webServer.cpp`, `src/appGlobals.h` — отдельный ETag веб-страниц (`WEB_ETAG`), `GITHUB_PATH` указывает на этот репозиторий.

**Веб-интерфейс** (`data/MJPEG2SD.htm`)
- Ползунки руля и газа заменены двумя экранными джойстиками с мультитачем, кнопками фар и смены сторон.
- Управление включается автоматически при открытии трансляции.

## English summary

Hot Wheels–size (1:64) FPV RC car controlled from a phone browser over Wi-Fi, based on
[s60sc/ESP32-CAM_MJPEG2SD](https://github.com/s60sc/ESP32-CAM_MJPEG2SD) v10.9.6 for the **Seeed XIAO ESP32S3 Sense**.

- Two on-screen multitouch joysticks (steering / throttle + reverse), lights button and a button to swap joystick sides; shown automatically when the live stream opens.
- Steering servo end points and centre, motor direction invert, motor soft start, Wi-Fi TX power — all in *Edit Config → RC Config*.
- Failsafe: motor stops and steering centres when the browser connection is lost.
- Pins: D0 servo, D1/D2 MX612E INA/INB, D3 lights. Do not use D8–D10 (SD card).
- Build: Arduino esp32 core ≥ 3.1.1, board XIAO_ESP32S3, OPI PSRAM, partition *8M with spiffs (3MB APP/1.5MB SPIFFS)*.
